## Featured Research

### Dual-Timescale Behaviour Modelling for Customer Conversion Prediction

My Master's research investigated how short-term purchasing activity and long-term customer engagement patterns can be combined to predict subsequent purchasing behaviour.

Using the Instacart dataset, I developed and evaluated a hybrid deep learning framework against traditional machine learning and single-timescale neural models.

**Key research findings:**
- Dual-Timescale model ROC-AUC: **0.8750**
- Gradient Boosting baseline ROC-AUC: **0.8413**
- Evaluated predictive performance using ROC-AUC, F1-score, and precision.
- Applied SHAP to interpret behavioural features in the Gradient Boosting baseline
